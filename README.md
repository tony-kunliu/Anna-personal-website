## Deploy

Enable GitHub Pages on this repository (Settings → Pages → Deploy from a
branch → `main` → `/ (root)`). The site is then live at
`https://tony-kunliu.github.io/Anna-personal-website/`.

To use a custom domain, add a `CNAME` file with the domain name and point
the domain's DNS at GitHub Pages.
